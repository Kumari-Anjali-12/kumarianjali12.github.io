Jarvis 2.0: AI Virtual Assistant

Python Speech Recognition gTTS PyAudio Web Automation

Project Summary

**Jarvis 2.0** is a sophisticated, voice-activated virtual desktop assistant designed to automate routine tasks and provide quick, hands-free access to information. Built primarily with Python, this project focuses on robust speech-to-text processing and efficient command execution, moving beyond simple scripting to offer a more interactive user experience.

Key Features and Functionalities

  • **Voice Command Interface:** Utilizes the `SpeechRecognition` library to accurately transcribe spoken queries into text commands.
  • **Task Automation:** Capable of opening specific applications, playing music, setting reminders, and performing system operations using dedicated Python modules.
  • **Information Retrieval:** Can fetch real-time data like current time, date, and weather, and answer general knowledge questions by integrating with APIs and web scraping tools.
  • **Text-to-Speech Feedback:** Leverages the **Google Text-to-Speech (gTTS)** library to provide natural and responsive audio feedback to the user, enhancing the assistant's personality and usability.

Learning & Development Focus

Developing Jarvis 2.0 strengthened my skills in **API integration**, **desktop automation**, and handling **real-time audio stream processing**. It was a practical exercise in engineering a system where multiple components (audio, processing, feedback) must work synchronously and reliably.
