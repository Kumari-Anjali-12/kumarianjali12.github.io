Mental Health Mirror

Python TensorFlow OpenCV NLP (NLTK) Deep Learning (CNNs, LSTMs)

Project Summary

The Mental Health Mirror is a pioneering multi-modal system designed to assess an individual's emotional state by analyzing both text (spoken or typed) and facial expressions. The goal is to provide a non-intrusive, real-time tool for monitoring emotional well-being, which can be invaluable in preliminary mental health screening.

Key Features and Modules

  • Facial Emotion Recognition: Uses a Convolutional Neural Network (CNN) trained on the FER2013 dataset via OpenCV to detect seven primary emotions (anger, disgust, fear, happiness, sadness, surprise, neutral) in real-time video feeds.
  • Text Sentiment Analysis: Employs Natural Language Processing (NLP) techniques, including an LSTM model, to analyze the sentiment of user input (e.g., diary entries or transcribed speech).
  • Multi-Modal Fusion: A custom-designed algorithm combines the confidence scores from the visual and textual models to output a final, more robust emotional assessment score, mitigating the noise from single-source detection.

Real-World Impact

This project demonstrates the powerful application of Deep Learning in social and human-centric computing. It has potential uses in remote patient monitoring, user experience testing, and creating more empathetic AI interfaces.
